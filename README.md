# Coffee_Sales
•	Problem Statement: Optimize coffee shop inventory management and staff scheduling based on transaction trends.

•	Key Findings: Sales are evenly distributed across times of day (~$38K Morning/Afternoon/Night), but product preference heavily favors milk-based options (Latte, Americano with Milk, Cappuccino).

•	Recommendations: Focus marketing campaigns on premium offerings (Latte) and align staffing with peak weekday hours (Tuesdays and Fridays).
